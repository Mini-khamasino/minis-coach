# Changelog

## 3.0.2 — 2026-10-25
- **Exercise names now displayed in English.** Gym exercises show their official English names in both languages (Arabic names still work in search).
- **Added "No Equipment" filter.** Train → program: "🙌 I don't have equipment" switches to a bodyweight-only program and bodyweight exercises on the body map. The exercise library has the same chip (starts on when the setting is on). The AI assistant knows the setting and can search bodyweight-only.
- **New AI chat interface.** The Coach tab opens on a chat thread (your messages and the coach's replies as bubbles). "Full history" shows the coach's own messages, reactions and the "ask an AI" prompt, with a count of unread ones.

## 3.0.1 — 2026-10-25
- Fixed "KeyPath lastAt on object store reports is not indexed" when sending feedback.

## 3.0.0 — 2026-10-25
- Feedback and automatic error reports, exercise library (870+ with animations), custom routines, AI coach v2. See `docs/v3-notes.md`.
